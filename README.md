# Portfólio · Lara Lopes

**https://laraalexlopes.github.io**

Site de portfólio em React e Vite.

## Rodar localmente

```bash
npm install
npm run dev
```

## Editar o conteúdo

Todo o texto (experiências, projetos, competências e formação) fica em `src/data.js`.

## Publicar

O workflow `.github/workflows/deploy.yml` publica no GitHub Pages a cada push na branch `main`.
